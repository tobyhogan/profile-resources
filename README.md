Development Process:


- Atomic commits, commiting after a specific feature change, with each commit being in the format: "version x.x.x", for instance: "version 1.3.2".

- There will then be a version-logs.txt file, there can then be included, a list of annotated versions for any significant or remember-worthy changes.

- This means that any change can be reverted to or checked easily, and finding the commit hash, improving the overall workflow.
